# 🛠️ Hardware & Robotics Engineering Vault

A collection of my journey through embedded systems, robotics, and custom hardware solutions. These projects range from competitive robotics to solving real-world supply chain challenges.

## 🌟 Featured Projects

### **Custom ARGB PC Controller**
*A solution-driven project born out of necessity when local components were unavailable.*
* **The Problem:** No available ARGB controllers in the local market.
* **The Build:** Developed a custom hardware controller using **Arduino** and the **ALA (Arduino Lighting Animation)** library.
* **Control:** Integrated a Serial-to-Terminal interface allowing for real-time lighting customization via COM port communication.
* **Keywords:** `Arduino`, `C++`, `Serial Communication`, `Custom Hardware`

### **Autonomous Sumo Bot**
*A high-speed combat robot designed for opponent tracking.*
* **Logic:** Features an ultrasonic sensor mounted on a high-speed servo, creating a "radar" sweep to lock onto opponents.
* **Challenge:** Implemented reactive combat algorithms. While edge-detection was limited by sensor availability, the tracking and engagement logic were fully optimized.
* **Keywords:** `Robotics`, `Autonomous Logic`, `Sensor Fusion`, `Arduino`

## 🏡 IoT & Automation

### **Smart Irrigation System**
* **Function:** Automated soil-moisture monitoring and maintenance.
* **Hardware:** Soil hygrometers coupled with a hydraulic pump system.
* **Outcome:** Successfully maintained a 100% uptime rate during its deployment phase, proving system reliability.

### **Pico Web Server**
* **Function:** Local network IoT hub for home automation.
* **Hardware:** **Raspberry Pi Pico W**.
* **Interface:** Hosted a lightweight web server to toggle room lighting via any browser-enabled device on the local network.
